# Super Mario World 1 - HTML5 Edition

🎮 超级马里奥兄弟一代 **World 1-1 / 1-2 / 1-3** 三关 HTML5 复刻版

## ✨ 特性

- ✅ **纯 HTML5 + JavaScript** - 无需安装，浏览器直接运行
- ✅ **三关完整复刻** - World 1-1 草地 / 1-2 地下 / 1-3 天空运动
- ✅ **复古像素画风** - 精灵图 + 程序化绘制结合
- ✅ **完整物理系统** - 重力、跳跃、碰撞检测、固定时间步长（60Hz 物理 + 40fps 渲染）
- ✅ **丰富敌人** - 板栗仔、绿/红库巴、飞行库巴、铁锤兄弟、食人花
- ✅ **道具系统** - 蘑菇（变大）、火焰花（发火球）、无敌星、1UP
- ✅ **特色机关** - 水管传送、升降平台、移动平台、坠落平台、弹簧板
- ✅ **Web Audio 音效** - 三关独立 BGM + 跳跃/金币/受伤/死亡/弹簧等 SFX
- ✅ **暂停功能** - P 键暂停，BGM 同步挂起
- ✅ **关卡选择界面** - 标题画面支持鼠标点击或 1/2/3 快捷键选关
- ✅ **过关烟花** - 旗杆后粒子烟花动画再过渡下一关

## 🚀 快速开始

### 方法 1：本地服务器（推荐）
```bash
# Node.js
npx serve .

# Python
python -m http.server 8000
```

浏览器打开 `http://localhost:8000`

### 方法 2：直接打开
双击 `index.html` 即可（项目兼容 `file://` 协议）

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| ← → / A D | 左右移动 |
| ↑ / 空格 / W | 跳跃 |
| ↓ / S | 蹲下（大马里奥） |
| Shift / X | 发射火球（火焰状态） |
| R | 重新开始 |
| P | **暂停 / 恢复** |
| M | 静音 |
| ESC | 退出 |
| 1 / 2 / 3 | 标题画面选关 |

## 📋 关卡内容

### World 1-1 · 草地平原
经典开局。地面 + 砖块 + 问号箱 + 4 根水管 + 阶梯 + 旗杆。17 个板栗仔、数只库巴。

### World 1-2 · 地下洞窟
深色主题。7 个深渊坑、3 部升降平台、4 株食人花、23+ 个板栗仔 + 绿/红库巴。隐藏块 + 多金币砖块。

### World 1-3 · 天空运动关 ☁️
无连续地面，全靠平台/桥/树冠。7 段式布局：
1. **入口** — 树冠平台 + 桥
2. **桥区** — 三段木桥 + 上方树冠高阶路线
3. **弹簧区** — 弹簧板跃上高处
4. **移动平台** — 水平/垂直移动平台渡坑
5. **坠落平台** — 踩上即抖、18 帧后坠落
6. **高低路线** — 下层桥、上层树冠双路线
7. **阶梯 + 旗杆** — 8 级阶梯进城堡

敌人：板栗仔、库巴、**飞行库巴（绿=上下飞、红=水平飞）**、**铁锤兄弟**、食人花。

## 🍄 道具系统

| 道具 | 出现条件 | 效果 |
|------|----------|------|
| 超级蘑菇 | 顶问号箱 / 隐藏块 | 小马里奥 → 大马里奥 |
| 火焰花 | 特定砖块（大马里奥击打） | 可发射火球 |
| 无敌星 | 特定砖块 | 短时间内碰敌即杀 |
| 1UP 蘑菇 | 特定隐藏块 | +1 命 |
| 金币 | 问号箱、砖块、收集品 | +100 分 / 累计 100 → 1UP |

## 🏆 计分

- 金币：+100
- 踩扁板栗仔 / 库巴：+200
- 踩停移动龟壳再踢出：+200
- 火球击杀：+200
- 旗杆高度奖励：每格 +100
- 时间奖励：剩余时间 × 50

## 🎨 技术栈

- **HTML5 Canvas** - 渲染（精灵图 + 程序化像素绘制）
- **Vanilla JavaScript** - 游戏逻辑（无框架、无打包）
- **Web Audio API** - BGM 与 SFX（方波/三角波/锯齿波合成）
- **固定时间步长循环** - 物理 60Hz 累加器、渲染 40fps 独立采样，解决插电/电池帧率差异

```
│   ├── paratroopa.js       # 飞行库巴 (绿=垂直飞、红=水平飞)
│   ├── hammer-bro.js       # 铁锤兄弟 + Hammer 抛射体
│   ├── piranha-plant.js    # 食人花
│   ├── coin.js / mushroom.js / fireball.js
│   ├── moving-platform.js  # 移动平台 (水平/垂直/对角)

│   ├── elevator.js         # 升降平台
│   ├── pipe-system.js      # 水管传送系统
│   ├── level.js            # 三关地图生成器
│   ├── renderer.js         # 渲染 (瓦片/精灵/粒子/覆盖层)
│   ├── input.js            # 键盘输入
│   ├── music.js            # Web Audio BGM + SFX
│   └── game.js             # 主循环 / 碰撞 / 状态调度
├── README.md               # 本文件
├── DESIGN_NOTES.md         # 关卡设计与架构经验
└── DEV_NOTES.md            # 开发历程笔记
```
