# Super Mario World 1-1 - HTML5 Edition

🎮 超级马里奥兄弟一代 World 1-1 的 HTML5 复刻版

## ✨ 特性

- ✅ **纯 HTML5 + JavaScript** - 无需安装，浏览器直接运行
- ✅ **完整关卡** - 经典 World 1-1 关卡复刻
- ✅ **复古画风** - 像素风格的画面和配色
- ✅ **流畅控制** - 马里奥移动、跳跃、重力物理
- ✅ **敌人 AI** - 板栗仔（Goomba）自动巡逻
- ✅ **收集系统** - 金币、问号方块
- ✅ **碰撞检测** - 瓦片、敌人、金币
- ✅ **摄像机跟随** - 横向卷轴效果

## 🚀 快速开始

### 方法 1：本地服务器（推荐）
```bash
# 使用 Node.js
npx serve .

# 或使用 Python
python -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`

### 方法 2：直接打开
双击 `index.html` 文件，浏览器会自动打开

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| ← → 或 A D | 左右移动 |
| 空格 或 ↑ 或 W | 跳跃 |
| R | 重新开始 |
| ESC | 退出 |

## 📋 游戏内容

### 世界 1-1 元素

- **地形**
  - 地面（带草地）
  - 砖块平台
  - 问号方块（含金币）
  - 绿色管道（4 个）
  - 阶梯（可攀爬）
  - 终点旗杆

- **敌人**
  - 17 个板栗仔（Goomba）

- **收集品**
  - 9 个金币
  - 问号方块内的金币

- **目标**
  - 到达终点旗杆通关
  - 收集金币和击败敌人获得高分

## 🎯 游戏目标

1. **移动** - 使用方向键或 WASD 控制马里奥
2. **跳跃** - 按空格跳过障碍和踩扁敌人
3. **收集** - 获取金币增加分数
4. **通关** - 到达旗杆完成关卡

## 🏆 计分系统

- 收集金币：+100 分
- 踩扁板栗仔：+200 分

## 🎨 技术栈

- **HTML5 Canvas** - 游戏渲染
- **Vanilla JavaScript** - 游戏逻辑
- **CSS3** - 界面样式
- **无依赖** - 纯原生代码

## 🌐 浏览器兼容性

- ✅ Chrome 90+
- ✅ Firefox 88+
- ✅ Safari 14+
- ✅ Edge 90+

## 📱 响应式支持

支持桌面端和移动端（需要触摸屏支持）

## 🔧 开发

### 项目结构
```
mario-1level-h5/
├── index.html          # 入口页面
├── css/
│   └── style.css       # 样式
├── js/
│   ├── config.js       # 游戏配置与颜色
│   ├── game-state.js   # 游戏状态管理
│   ├── mario.js        # 马里奥角色
│   ├── goomba.js       # 板栗仔敌人
│   ├── coin.js         # 金币
│   ├── level.js        # 关卡地图数据
│   ├── renderer.js     # 渲染逻辑
│   ├── input.js        # 键盘输入处理
│   └── game.js         # 游戏主循环
└── README.md           # 项目说明
```

### 修改游戏
编辑 `js/` 下对应的模块文件，用本地服务器打开即可看到效果。

### 自定义关卡
在 `js/level.js` 的 `generateLevelMap()` 函数中修改关卡数据。
